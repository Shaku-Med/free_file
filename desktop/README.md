# Memories Desktop

Native Electron UI for Memories. This is a **separate desktop app** (not a webview of the website). UI/layout only for now — no API or database.

## Run

```bash
cd free_file/desktop
npm install
npm run dev
```

## What's included

- Frameless window + custom title bar
- Sidebar: Home, Subscriptions, Reels, Library, Playlists, Brozy Studio
- Top bar: search, upload, notifications
- Home feed with chips + continue watching
- Watch page layout (player chrome + related rail)
- Reels fullscreen-style layout
- Library / Playlists / Studio shells with mock data
